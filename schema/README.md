# Schema + Data Export

This folder contains portable SQL exports for BDJ Ledger.

## Files
- `sqlite_schema.sql`: SQLite schema
- `mysql_schema.sql`: MySQL schema (utf8mb4/InnoDB)
- `export_data.py`: exports data from the active SQLite database into INSERT statements
- `sqlite_data.sql`: generated by `export_data.py`
- `mysql_data.sql`: generated by `export_data.py`
- `sqlite_schema_and_data.sql`: generated (schema + data)
- `mysql_schema_and_data.sql`: generated (schema + data)

## Export data (recommended)
From `bdj_ledger/`:

```powershell
python .\schema\export_data.py --sqlite .\ledger.db
```

If your DB is elsewhere or you use the `DATABASE` env var, you can omit `--sqlite`:

```powershell
python .\schema\export_data.py
```

If the app is configured to use `MYSQL_URL` or `POSTGRES_URL`, the exporter can pull from that database and still output a MySQL-ready insert dump:

```powershell
python .\schema\export_data.py --source auto
```

To generate a re-import friendly dump (clears tables before inserts):

```powershell
python .\schema\export_data.py --sqlite .\ledger.db --clean
```
